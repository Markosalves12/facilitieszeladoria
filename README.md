# FACILITIES ZELADORIA
## 🧩 Principais Funcionalidades

- ✅ Criação e acompanhamento de **ordens de serviço de jardinagem**
- 📷 **Coleta de imagens** para comprovação visual da execução
- 📊 **Relatórios automáticos** em **PDF** e **Excel**
- 🔐 **Perfis com permissões específicas**: Gestores, Gerentes e Operadores
- 📅 Registro de histórico de execução com datas, horários e responsáveis
- 📌 Integração com dados geográficos (opcional)

## ⚙️ Tecnologias Utilizadas

- **Backend**: Django 4.x
- **Banco de dados**: PostgreSQL ou SQLite
- **Relatórios**: `reportlab`, `openpyxl`, `pandas`
- **Imagens**: `Pillow`, upload via painel ou API
- **Autenticação e permissões**: Django Auth + controle customizado por função
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap (opcional)
